Admin Editor — usage (updated)

Open /admin-editor.html to run the full 2D plan editor.

Features:
- Upload images to the local Media Library (stored in your browser).
- Add images to the canvas, drag, scale, rotate, and annotate.
- Grid display, snap-to-grid, and presets for Cabin, Barn, and Site plans.
- Measurement tool calibrated by "Pixels per unit" and unit selector (px/ft/m).
- Export PNG/PDF and Save/Load JSON project files.
- Optional upload to a local Node server (run server.js) to persist files to ./uploads.
- Set a canvas image as the site hero locally (stored in localStorage key dawkins-site-content-v11).

Run local upload server (optional): see README_DEPLOY.md
