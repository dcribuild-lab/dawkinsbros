# Dawkins photo shelf

Put every new job in its own dated folder:

`media/projects/YYYY/MM-project-name/`

Example: `media/projects/2026/09-smith-deck/`

Inside each job folder, number photographs in the order you want people to see them:

`01-before.jpg`, `02-during.jpg`, `03-finished.jpg`

Keep the original camera photographs in a separate safe folder on your computer. Put only copies sized for the website here. Use the same date on the job photo folder and the customer portal project so everything stays easy to find.
